# Photo Score

사진의 픽셀을 브라우저에서 분석해 **7개 항목 점수, 종합 점수, 등급, 촬영·후보정 팁**을 제공하는 웹 도구입니다. 로그인이나 API 키 없이 로컬 사진을 불러와 사용할 수 있습니다.

소개 페이지에서는 “AI”라는 표현을 사용하지만, 현재 구현의 핵심은 히스토그램·에지·색 분포·선명도 등의 **수치와 규칙에 기반한 평가**입니다. 외부 생성형 AI API나 학습된 모델을 호출하는 방식은 아닙니다.

## 주요 기능

- JPG·PNG·WebP 등 브라우저 지원 이미지의 드래그 앤 드롭
- 구도·노출·피사체·보케/심도·색감·선명도·창의성 평가
- 100점 기준 종합 점수와 등급 표시
- 측정값과 점수에 따른 상세 개선 제안 및 퀵 팁
- 감지한 구도와 추정 피사체 위치를 표시하는 SVG 오버레이
- 새 사진 선택과 재분석

## 사용 기술

| 기술 | 용도 |
| --- | --- |
| HTML / CSS / JavaScript | 파일 선택, 분석 상태, 결과 UI |
| FileReader / Image | 로컬 사진 읽기와 디코딩 |
| Canvas 2D / ImageData | 축소 이미지의 픽셀 분석 |
| SVG | 구도 가이드와 피사체 위치 시각화 |
| 자체 통계·이미지 처리 로직 | 히스토그램, 에너지 맵, 색조 분포, 라플라시안 기반 선명도 측정 |
| Google Fonts | 웹 폰트 |

별도 백엔드나 패키지 설치·빌드 과정이 없습니다. 화면과 분석 코드는 `index.html` 안에 함께 들어 있습니다.

## 실행 방법

GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풀고 `index.html`을 브라우저에서 여세요.

Git과 Python 3가 설치되어 있다면 로컬 서버로 실행할 수 있습니다.

```sh
git clone https://github.com/Velvitty/Photo_Scorer.git
cd Photo_Scorer
python3 -m http.server 8000 --bind 127.0.0.1
```

- 프로그램: <http://localhost:8000/index.html>
- 소개·사용 안내: <http://localhost:8000/manual.html>

## 사용 방법

1. 사용권 계약서의 체크 항목을 확인하고 **동의하고 시작하기**를 누릅니다.
2. 업로드 영역을 클릭하거나 사진 한 장을 끌어다 놓습니다.
3. 미리보기를 확인하고 **분석 시작**을 누릅니다.
4. 종합 점수와 항목별 점수, 구도 표시 및 개선 팁을 확인합니다.
5. **다시 선택**으로 다른 사진을 불러와 비교합니다.

사진을 자동으로 보정하거나 원본을 덮어쓰는 도구는 아닙니다. 제공되는 팁을 참고해 촬영 또는 별도 편집 도구에서 수정한 뒤 다시 분석할 수 있습니다.

## 평가 항목

| 항목 | 종합 점수 비중 | 주요 분석 내용 |
| --- | --- | --- |
| 구도 | 25% | 9×9 에너지 맵, 삼분법·황금비율·나선·대각선·중앙·사다리꼴 패턴, 균형과 대칭 |
| 피사체 | 20% | 선명한 영역의 집중도와 피사체·배경 분리 정도 |
| 노출 | 15% | 256단계 휘도 히스토그램, 밝기, 클리핑, 명암 범위 |
| 색감 | 15% | 12구역 색조 분포, 채도와 채도 변화 |
| 선명도 | 10% | 라플라시안 계열 연산으로 얻은 고주파 성분 |
| 보케/심도 | 10% | 배경 선명도, 분리비, 선명 영역의 비율 |
| 창의성 | 5% | 밝기·대비·색·구도 등 여러 지표를 조합한 규칙 기반 점수 |

종합 점수는 위 비중을 적용한 가중합을 반올림합니다. 계산량을 줄이기 위해 분석용 이미지는 **긴 변 최대 800px**로 축소하며, 원본 파일은 변경하지 않습니다.

## 등급 기준

| 점수 | 등급 |
| --- | --- |
| 95 이상 | S+ |
| 90~94 | S |
| 85~89 | A+ |
| 80~84 | A |
| 75~79 | B+ |
| 70~74 | B |
| 60~69 | C |
| 50~59 | D |
| 50 미만 | F |

실제 코드에는 9개 등급이 있습니다. 소개 페이지의 “8단계”는 D/F를 한 구간으로 합쳐 표현한 안내입니다.


**파일 읽기 → 분석용 캔버스 축소 → 픽셀 지표 계산 → 항목별 점수 → 가중 종합 점수 → 등급·피드백 생성 → 결과 표시** 순서로 처리합니다. 코드에는 분석 엔진, 파일 처리, 피드백 생성, 구도 오버레이, 결과 렌더링 부분이 포함되어 있습니다.

| 코드 구성요소 | 역할 |
| --- | --- |
| `handleFile()` / `startAnalyze()` | 파일 읽기, 분석용 이미지 준비 |

| `getGrade()` / `renderResults()` | 등급 분류와 결과 화면 구성 |

## 데이터 처리와 해석상의 한계

- 사진은 브라우저 메모리에서 분석합니다. 분석을 위해 원격 서버에 사진을 업로드하거나 계정을 만드는 기능은 없습니다.
- Google Fonts 로딩에는 네트워크 요청이 발생하므로 “로컬 분석”이 웹 페이지의 모든 요청이 없다는 뜻은 아닙니다.
- 점수는 사진을 연습하고 비교하기 위한 참고 지표입니다. 작품의 의미·스토리·촬영 의도나 예술적 가치를 객관적으로 판정하지 않습니다.
- 피사체와 심도는 픽셀의 선명도 분포로 추정합니다. 사람·사물의 의미를 인식하거나 실제 거리·조리개 값을 측정하지 않습니다.
- 800px 축소, 이미지 압축, 노이즈, 강한 후처리에 따라 결과가 달라질 수 있습니다. 보케를 의도하지 않은 풍경·기록 사진은 해당 항목이 낮아도 결함을 뜻하지 않습니다.

## 문제 해결

- 업로드가 되지 않으면 JPG·PNG·WebP로 변환해 다시 시도하세요. RAW·HEIC 등의 디코딩 지원은 브라우저에 따라 다릅니다.
- 분석이 지연되면 큰 원본을 줄인 복사본으로 시도하고 다른 메모리 사용량이 큰 탭을 닫으세요.
- 세부 점수와 추천이 기대와 다르면 사진의 촬영 의도와 측정 지표를 함께 보세요. 점수를 높이기 위한 보정이 항상 더 좋은 사진을 만드는 것은 아닙니다.
